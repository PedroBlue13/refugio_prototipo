# Visual QA

Inspect the implementation systematically before declaring it finished.

## Checklist
- Alignment and grid consistency
- Spacing rhythm
- Typography hierarchy
- Text wrapping
- Overflow and clipping
- Image cropping
- Border/radius consistency
- Shadows and surface hierarchy
- Icon size and alignment
- Hover/focus/active/disabled states
- Loading/empty/error states
- Modal and dropdown layering
- Sticky/fixed element collisions
- Responsive breakpoints
- Dark mode if supported
- Browser zoom
- Long and short content
- Accessibility-visible focus

## Method
Fix root causes rather than adding one-off offsets.
Re-test neighboring breakpoints after every structural responsive change.
