# Final Polish

Do not add major new concepts. Refine what already exists.

## Passes
### Visual
Fix awkward spacing, inconsistent type, weak alignment, accidental repetition, and unfinished surfaces.

### Interaction
Check every button, link, form, dropdown, modal, tab, menu, tooltip, and keyboard path.

### Responsive
Inspect narrow phones through large monitors. Remove overflow and awkward dead space.

### Content
Replace placeholder copy, broken labels, accidental lorem ipsum, fake metrics, and inconsistent terminology.

### Accessibility
Verify semantics, focus, contrast, labels, alt text, and reduced motion.

### Engineering
Remove dead code, debug logs, unused imports, duplicated utilities, fragile magic values, and obvious warnings.

## Completion rule
Only call the frontend finished when its default state and edge states both feel intentionally designed.
