# UI/UX Review

Review the interface as a product experience.

## Evaluate
- Can a new user understand the page purpose quickly?
- Is the primary action obvious?
- Is information hierarchy clear?
- Are repeated patterns consistent?
- Are forms economical and understandable?
- Do errors explain recovery?
- Are destructive actions protected?
- Is system status visible?
- Are loading and empty states useful?
- Are labels written in the user's language?
- Is cognitive load unnecessarily high?
- Does mobile preserve task completion?

## Output
Prioritize findings:
1. Blocking usability issues.
2. High-impact clarity problems.
3. Consistency and interaction issues.
4. Visual polish.
5. Optional enhancements.

For each important issue, recommend a concrete change rather than a vague critique.
