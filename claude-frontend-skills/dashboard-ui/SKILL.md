# Dashboard UI

Optimize dashboards for decisions, not decoration.

## Structure
- Put critical status and actions first.
- Use summary metrics only when they change decisions.
- Group related controls and data.
- Keep filters discoverable and persistent when useful.
- Use tables for precise comparison.
- Use charts for patterns, distributions, and trends.
- Provide drill-down paths.

## Data display
- Use correct units.
- Include time ranges and comparison context.
- Handle zero, missing, loading, stale, and error states.
- Keep chart legends and labels readable.
- Avoid chart junk and excessive colors.
- Reserve strong visual emphasis for exceptions and actions.

## Operational UX
Support search, filters, sorting, pagination, bulk actions, export, confirmation, undo where appropriate, and meaningful empty states.
