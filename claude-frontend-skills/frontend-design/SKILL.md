# Frontend Design

Establish a deliberate visual direction before coding.

## Workflow
1. Identify the product, audience, primary action, and emotional tone.
2. Choose a recognizable visual language rather than default SaaS styling.
3. Define typography, spacing, color, radius, borders, shadows, and motion as design tokens.
4. Build a clear hierarchy: primary action, supporting content, secondary actions.
5. Prefer asymmetric or editorial composition when it improves character.
6. Make every decorative element support the product story.
7. Produce working, production-oriented code rather than static mockups.

## Quality bar
- Avoid generic gradient-heavy AI aesthetics.
- Avoid arbitrary glassmorphism.
- Avoid excessive cards when grouping can be achieved with spacing and typography.
- Maintain excellent contrast and readable line lengths.
- Use icons consistently.
- Make empty, loading, error, hover, focus, active, and disabled states intentional.
- Keep the interface visually coherent across pages.

## Before finishing
Audit alignment, rhythm, hierarchy, consistency, responsiveness, accessibility, and visual polish.
