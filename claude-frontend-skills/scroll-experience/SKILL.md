# Scroll Experience

Treat scrolling as a narrative control.

## Rules
- Start with a usable non-animated document flow.
- Use sticky sections only when they improve comprehension.
- Reveal information progressively.
- Keep scroll-linked motion restrained and performant.
- Prefer IntersectionObserver for threshold-based reveals.
- Avoid hijacking native scrolling.
- Avoid excessive parallax.
- Make pinned sections easy to escape.
- Ensure content remains understandable with reduced motion.

## Storytelling pattern
1. Establish context.
2. Introduce the central object or idea.
3. Reveal features or evidence progressively.
4. Transition toward a decision or CTA.
5. End with a stable, readable final state.

## Verify
Test trackpads, mouse wheels, touch scrolling, keyboard navigation, reduced motion, short screens, and browser resizing.
