# INSTRUCTIONS — SITE REFÚGIO BARBER

Crie um site moderno, responsivo e visualmente marcante para a **Refúgio Barber**, utilizando como referência principal a identidade visual presente no material promocional fornecido.

O projeto precisa preservar a personalidade atual da marca: **preto predominante, visual urbano, masculino, premium, energético e com cores vibrantes aplicadas pontualmente**.

A proposta não é criar uma barbearia clássica em tons de marrom, madeira e dourado. A identidade da Refúgio é mais contemporânea, ligada a **streetwear, grafite, neon discreto, exclusividade e cultura urbana**.

# 44. GSAP


```javascript
gsap.from(".service-card", {
  opacity: 0,
  y: 40,

  stagger: 0.12,
  scrollTrigger: {

  }
```

```javascript
gsap.to(".brush-decoration", {

    trigger: ".brush-decoration",

  }
```

# 45. Performance e acessibilidade

Priorizar animações com:

- `transform`
- `opacity`

Evitar animações pesadas de:

- width;
- height;
- top;
- left.

Respeitar:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

Nenhuma animação deve impedir o usuário de:

- clicar em agendar;
- usar o menu;
- abrir WhatsApp;
- visualizar serviços;
- interagir com o mapa.
